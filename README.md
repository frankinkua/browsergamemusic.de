# Browser Game Music (browsergamemusic.de)

Category: music-media

## Concept
A playful music toy for game soundtracks: a step-sequencer chiptune maker built with the Web Audio API (pick tempo, scale, 4 instruments, 16 steps), plus short articles on how game music loops and adapts. Patterns can be shared via the URL hash.

## Look
Retro arcade: dark purple background, neon pink/cyan, pixel font for headings only, CRT-scanline effect that respects prefers-reduced-motion.

## File Structure
- `index.html`: Main landing page with the interactive Web Audio API sequencer and articles on VGM.
- `impressum.html`: Impressum page (legal notice).
- `datenschutz.html`: Privacy policy page.
- `404.html`: Custom error page in retro style.
- `style.css`: All styling, including the CRT-scanline effect and responsiveness.
- `app.js`: Logic for the sequencer, Web Audio synthesis, and state serialization via URL hash.
- `favicon.svg`: Inline SVG favicon.
- `fonts/`: Self-hosted pixel font for headings (Press Start 2P).
- `robots.txt` & `sitemap.xml`: SEO fundamentals.
- `CNAME`: Configuration for GitHub Pages custom domain.
